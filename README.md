# 脱敏映射室（Mask Room）

一个**完全本地**运行的文本脱敏与可追溯还原系统，不调用任何外部密钥服务。
隐私工程师用它在本机核对脱敏规则：敏感片段被替代 token 遮住，获准人员可凭
**token + 用途说明**对单个片段申请还原，所有成功/失败都写入追加式链式审计。

## 构建与运行

```bash
cargo build --locked

# 测试 + 演示
cargo test --all-targets
cargo run --locked -- --addr 127.0.0.1:5223
# 浏览器访问 http://127.0.0.1:5223 ，页面标题为「脱敏映射室」
```

可选参数：`--data-dir ./maskroom-data`（默认 `./maskroom-data`，目录 0700、密钥文件 0600）。
**首次启动**在本地生成 32 字节主密钥与第一代派生种子；测试中则使用确定性测试密钥。

## 能力与设计要点

- **带版本的规则**：内置 `email`、`idcard`（18 位且校验位合法）、自定义 `regex`、
  整数闭区间 `range`。任意规则增删改/启停都会让租户规则集版本 `rule_version` 递增。
- **稳定 vs 随机 token**：同「租户 + 规则版本 + 原文」在同一密钥代次下，
  稳定规则复用同一 token 与映射；随机规则每次生成新 token。
- **跨租户不可关联**：token 标签 = HMAC(按代次+租户派生的密钥, 代次‖租户‖记录ID)。
  不同租户对同一原文得到完全不同的 token，且拿对方 token 无法通过校验；
  所有失败（格式错/签名错/他租户/映射缺失）返回**完全统一**的错误，不泄露归属。
- **重叠裁决**：命中收集后按「显式优先级 ↓ → 最长匹配 ↓ → 起点 ↑ → 规则 ID ↑」稳定排序，
  与已接受命中重叠者被压下，并给出原因（`overlap-higher-priority` /
  `overlap-longer-match` / `overlap-stable-tiebreak`）。
- **幂等再处理**：既有 token 的识别字符表与普通规则隔离，再处理时整段进入保护区，
  命中与 token 重叠的规则以 `inside-existing-token` 压下，输出保持不变。
- **加密映射**：原文以 AES-256-GCM 加密保存，AAD 绑定「代次‖租户‖记录ID」，
  防止跨记录/跨租户搬运密文；磁盘上只有密文，无任何明文片段。
- **还原审计**：还原只接受 `token` + 非空 `purpose`，成功写 `restore-ok`，
  失败写 `restore-denied`（均含用途与 token 的 SHA256 短指纹）；批量还原逐项独立，
  无效 token 不影响其他项。
- **密钥轮换 + 崩溃恢复**：轮换分「写新代次 → 提升 → 状态指向新代次 → 审计确认并提交」。
  旧代次永久保留，旧数据仍可解开，新写入只用新代次。任一阶段“掉电”后重启：
  未提升的新代次直接回滚；已提升的则前向完成，保证不会出现
  “一半映射用新代次、一半审计仍指旧代次”。
- **链式审计**：每条记录含前一条 SHA256 摘要、本条规范化 JSON 摘要与跨代次固定的
  HMAC 标签；插入/删除/改写任何一条都会在校验时报错。
- **导出**：仅包含已脱敏文本、规则元数据与审计摘要，绝不含原文、token 映射或密文。

## token 形态

```
MTKN-G<代次>-<16字节记录ID的base64url(22字符)>-<8字节HMAC标签(11字符)>
```
记录 ID/tag 使用自定义 base64url 字母表（`A-Z a-z 0-9 * ~`），`-` 仅作字段分隔，
保证可无歧义解析与整段识别。

## HTTP 接口（均为本地）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/`、`/app.js` | 单页界面 |
| POST | `/api/tenants` | 创建租户 |
| GET | `/api/tenants` | 列出租户 |
| GET/POST | `/api/rules` | 查看规则集（`?tenant=`）/ 登记新版本规则 |
| POST | `/api/rules/delete`、`/api/rules/toggle` | 删除 / 启停规则 |
| POST | `/api/preview` | 仅预览重叠裁决（不落库） |
| POST | `/api/redact` | 执行脱敏并加密保存映射 |
| POST | `/api/restore`、`/api/restore-batch` | 单个 / 批量还原（须带用途） |
| POST | `/api/keys/rotate`、GET `/api/keys` | 轮换 / 查看代次 |
| GET | `/api/audit`、`/api/audit/verify` | 审计记录 / 链完整性校验 |
| GET | `/api/export` | 导出（脱敏文本 + 规则元数据 + 审计摘要） |

## 测试覆盖（`cargo test --all-targets`）

跨租户不可关联、稳定/随机 token、重叠优先级+最长匹配、重复处理幂等、
批量部分失败与统一错误、密钥轮换保留旧数据、三个崩溃点的恢复（回滚/前向提交）、
审计改写与删除检测，以及一个启动真实二进制走完全部 HTTP 接口的端到端冒烟测试。
